# 04 测试计划

版本：v1.0 ｜ 日期：2026-10-01

## 1. 测试层次

| 层次 | 范围 | 方式 | 位置 |
| --- | --- | --- | --- |
| 单元 | 金额换算、日期周期、配置校验、zto 客户端主备切换与白名单、各来源字段映射、余额链、分类规则 | pytest，合成数据 | `tests/test_foundation.py` `test_zto.py` `test_sources.py` |
| 引擎 | 重复识别（同额多笔按时间配对）、中天充值、提现（到账/在途/超期/按发起人改科目）、账户间划转（含手续费）、人工结论覆盖、矛盾登记、余额核对状态、利润分科目、数据状态 | pytest，合成场景 | `tests/test_engine.py` |
| 报表 | 日/周/月报生成、亏损日紧急事项、上期对比、缺日提示、CSV BOM、图表 | pytest，合成 30 天 | `tests/test_reports.py` |
| 投递与流水线 | 知识库发布+回读校验、邮件（agently/SMTP）、投递台账只发一次、自愈补采、周报补采、运行锁 | pytest，伪造 HTTP/CLI/数据源 | `tests/test_delivery_pipeline.py` |
| 控制台 | 页面渲染、CSRF、路径穿越、人工处理与撤销、按行建规则、余额录入比对 | Flask test client | `tests/test_web.py` |
| 调度 | 时间解析、launchd plist、Windows 任务 XML | pytest | `tests/test_scheduler.py` |
| 安全 | 公开仓库防泄漏扫描 | pre-commit + CI | `scripts/leakcheck.py` `tests/test_leakcheck.py` |

CI：每次推送在 **macOS 与 Windows × Python 3.11 / 3.13** 上运行 lint、全部测试与 CLI 冒烟测试；测试数据全部为合成数据。

## 2. 真实数据验收（本机，私有）

| 编号 | 用例 | 判据 |
| --- | --- | --- |
| A1 | 回补 2026-08-25～09-30 全部来源，再次回补 | 全部成功；第二次变化行数为 0（幂等） |
| A2 | 9 月逐日对账 | 中天 30/30 天余额等式成立；有独立对照的银行/支付宝账户差额为 0 或有可解释原因 |
| A3 | 日记账与银行重复识别 | 对公账户日记账记录自动配对率 ≥ 90%，其余进入待核并说明原因 |
| A4 | 9-30 现金头寸与旧系统独立计算值一致 | 208,622.36 |
| A5 | 生成 9 月 30 份日报、4 份周报、1 份月报 | 全部成功，无未定义字段 |
| A6 | 端到端 `run daily`（投递演练） | 采集→对账→报表→邮件预览，运行记录成功 |
| A7 | 用户阅读日报 | 用户确认“看得懂、用得上” |
| A8 | 本机连续 7 天自动运行 | 无静默失败；失败均有日志、运行记录与通知 |

## 3. 回归原则

- 修复缺陷先补能复现的测试。
- 改动规则或口径时，用 9 月真实数据重算并比较月度利润、余额核对状态和待核数量的变化，变化需能解释。
