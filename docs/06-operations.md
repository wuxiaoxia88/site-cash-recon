# 06 运维手册

版本：v1.0 ｜ 日期：2026-10-01

## 1. 日常

| 时间 | 自动发生 | 需要人做的 |
| --- | --- | --- |
| 每天 12:10 | 采集昨日数据并自动补齐最近 7 天缺失/不完整的日期 → 对账 → 日报 → 知识库 + 邮件 | 看邮件中的“需要处理”，到控制台处理待核记录 |
| 每天 18:00 | 补跑仍不完整的日期和失败的投递 | — |
| 周一 12:20 | 上周周报 | — |
| 每月 3 日 12:30 | 上月月报（含 CSV） | — |
| 每周末 | — | 在控制台“余额录入”填写人工账户实际余额 |

## 2. 控制台

`cashrecon web` 或开机常驻后访问 http://127.0.0.1:8765 ：

- **待处理**：勾选记录，选择“忽略 / 确认为正常收支（可指定科目）/ 与另一笔重复 / 内部划转”，或选好科目后点“按科目建规则”，以后同类记录自动归类。所有操作立即重算并更新日报，可撤销。
- **当日流水**：按日期、账户查看每一笔及其对账状态和原因。
- **余额录入**：周末核对的实际余额，系统自动比对账面。
- **运行记录**：运行结果、投递回执、每个来源每天的采集情况；可手动“重新采集并计算该日”。

## 3. 常用命令

| 场景 | 命令 |
| --- | --- |
| 自检 | `cashrecon doctor` |
| 某天数据有误/上游补数后重算 | `cashrecon fetch --date D && cashrecon recon --date D` |
| 重新生成并补发某天日报 | `cashrecon deliver daily --date D`（已发过的不会重复发；确需重发加 `--force`） |
| 查看最近一次运行 | `logs/last-run.json`、`logs/cashrecon.log` |
| 立即备份 | `cashrecon backup` |

## 4. 排障

| 现象 | 检查 |
| --- | --- |
| 收到“运行失败”邮件 | 打开邮件中的日志路径；`cashrecon doctor`；修复后在控制台“完整日任务”或等待 18:00 补跑 |
| 日报标“数据有缺失” | 报表底部“对账与数据”表列出失败来源和原因；常见为 zto-cli 门户登录过期、上游采集未完成 |
| 余额“有差额” | 报表中列出差额来源；常见原因是银行短信漏采（余额链跳变）、日记账漏记或重复 |
| 没收到邮件 | 控制台“运行记录→投递”查看状态；`unknown` 表示已提交但无回执，不会自动重发以免重复 |
| 调度没跑 | `cashrecon schedule status`；macOS 查看 `logs/launchd-*.err.log` |

## 5. 备份与恢复

- 每次运行自动备份数据库到 `backups/cashrecon-YYYYMMDD.db`，保留 30 份。
- 恢复：停止调度 → 复制备份为 `data/cashrecon.db` → `cashrecon doctor` → `cashrecon recon --from … --to …`。

## 6. 安全

- `secrets.env`、`config.toml`、数据库、报表都在数据目录内，仅当前用户可读；不要复制到公共位置或提交到 Git。
- 控制台默认只允许本机访问；如需局域网访问，在 `secrets.env` 设置 `CASHRECON_WEB_PASSWORD` 并把 `[web] host` 改为 `0.0.0.0`。
- 系统对业务系统只读；门户写入功能未开启。
